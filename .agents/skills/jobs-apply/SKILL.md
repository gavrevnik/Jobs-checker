# Jobs Apply

Прочитай проектный AGENTS.md, [правила подготовки откликов](../../../discovery/application-workflow.md) и [политику адаптеров](../../../discovery/adapter-policy.md).

Если запрос ограничен подборкой, текстом, промптом или фиксацией уже отправленного отклика, выполни соответствующую часть процесса.

1. Если пользователь дал одну вакансию или список, работай с этим выбором. Для подборки возьми подходящие ранее размеченные вакансии Jobs Checker. Перед выдачей подборки проверь открытость и ключевые условия через [jobs-update](../jobs-update/SKILL.md#актуализация-вакансий-и-llm-отбор). Покажи ссылки, причину выбора, краткое описание компании и несколько релевантных фактов.
2. Проверь работодателя, объявление и форму. Возьми актуальное резюме и подтверждённые данные из локального профиля откликов. Учти уточнения пользователя, правила заполнения личных полей и [правило для права на работу в странах ЕС](../../../discovery/application-workflow.md#право-на-работу).
3. Предзаполни доступные поля в браузере, сохрани правки пользователя и оставь открытые формы для проверки. Поля гражданства и обращения к работодателю передай пользователю. Перечисли поля, которые нужно проверить или дополнить, и дай ссылку на использованный PDF резюме. Отправку выполняет пользователь.
4. Проверь, есть ли в форме поле для обращения, и сообщи результат при разборе вакансии. Для подходящих полей подготовь [черновики обращения](../../../discovery/application-workflow.md#обращение-к-работодателю) и [вспомогательный промпт для другой модели](../../../discovery/application-workflow.md#вспомогательный-промпт-для-письма). Если пользователь просит только промпты, выведи их отдельно для каждой указанной вакансии.
5. Если пользователь просит снять актуальные ответы перед отправкой, зафиксируй их как черновик. После его подтверждения отправки сохрани подтверждённые ответы и ссылку в карточке, обнови этап воронки и проверь запись.
