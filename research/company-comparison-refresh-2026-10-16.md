# Обновление первых колонок сравнения · 16.10.2026

Обработаны 71 существующая компания, без создания новых. Запрос пользователя разрешает локальное обновление API, веб-исследование и сохранение проверенных результатов. Knowledge/GitHub не публиковались. Прежде записи созданы проверенные WAL-aware SQLite-копии в стандартной локальной папке backups/company-discovery-refresh.

## Результат

- Новая колонка «Аналитическая культура» после целевых вакансий: существенные модельные теги, сводка, блоги, GitHub и датированные показатели аудитории.
- В первой колонке убрано описание, после размера добавлена строка основного офиса. Источники и уточнения доступны в карточке. Блоги убраны из описания бизнеса.
- У всех четырёх новых колонок есть раскрываемые источники с названием, назначением, датой, видом, запросом и результатом проверки. Сохранены ошибки и пустые ответы. У старых ссылок без даты она не выдумывается.
- Сохранены 107 новых проверенных observations; обновлены описательные поля 26 карточек. Проверены неизменность прежних scores, preferences, CRM status и notes. Прежние непроверенные observations не подтверждались массово.
- 44 компании имеют свежие теги культуры; 33 — ссылки на технические блоги/публикации, 10 — подтверждённые публичные GitHub, 13 — сведения об аудитории/масштабе. Остальные пробелы остаются пустыми. Чтение старой статьи не обновляет дату описанного стека.
- В ATS добавлены 42 записи после точного matching. Итоговая проекция целевых вакансий: 66 всего, 58 с недавним подтверждением присутствия источником. Это не число всех вакансий и не гарантия, что каждое объявление независимо проверено на сайте работодателя.

## Фактический сбор

Сначала APIs и matching, затем веб-поиск/чтение, затем сводка модели. После выявления неподдержанного native company filter Adzuna выполнен ограниченный корректирующий API-проход; сводки составлены после его завершения и учли оба прохода.

Всего 145 сетевых запросов по provider_requests: Adzuna 112 (41 исходная HTTP 400 и 71 успешный текстовый поиск), Greenhouse 10, Ashby 10, Lever 4, SmartRecruiters 7, Arbeitnow 1, Remotive 1. Первый проход ограничен 100 запросами (99 использовано); исправление и общие ленты — 50 (46 использовано). Использованы существующие cache, quota adapters и credentials. Новых API/платных Actors нет.

У Adzuna успешно проверена каждая из 71 компаний: Испания, analyst, возраст объявления до 365 дней, одна страница. Результаты чужих работодателей не импортированы. Это ограниченный поиск, а не полный мировой найм или архив закрытых вакансий за год. Arbeitnow/Remotive проверены как общие ленты с matching только по имеющимся компаниям. В SmartRecruiters доска Delivery Hero не завершена из-за лимита запросов на полные details; отсутствие полного результата не трактуется как отсутствие найма. SerpAPI и Jooble реализованы, но credentials отсутствуют, поэтому live-запросы не делались.

Веб-поиск выполнен для всех 71 компаний. Открыты официальные корпоративные страницы, Data/Engineering Blogs, GitHub и техническая документация. Недоступные страницы и одноимённые чужие проекты не использованы как проверенные факты. Например, quantum Pennylane и бухгалтерская Pennylane не смешивались. GitHub форк не доказывает production-использование технологии.

Это рабочие артефакты, не новая постоянная база.

## Проверка

135 tests / 17 files, TypeScript/Vite build, HTTP и MCP integration checks на отдельных временных SQLite; без live API в тестах. Skill прошёл quick_validate. В браузере на синтетической SQLite проверены порядок колонок, Company без описания/плашек, HQ, перенос ссылок, сводка, даты и блок источников в модалках. Прежние предупреждения Rollup/Zod и размера основного bundle не блокируют сборку.
