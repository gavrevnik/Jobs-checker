# Каталог источников и четыре компании · 21.10.2026

В сравнении компаний добавлена строка «Полезные ссылки». Она объединяет сохранённые website, Careers/ATS/LinkedIn, источники всех исследовательских критериев и рисков, collection_sources, вакансии за всю историю и новый опциональный Company.sourceLinks. Публичные URL объединяются без tracking; внутренние API не предлагаются как исследовательские источники. Главная блога и использованные статьи сохраняются отдельно, статьи вложены под блогом. Просмотр не запускает внешние API или пересчёт score.

«Вся информация» показывает компактную таблицу «Тип информации → Факты → Источники»: один тип сведений на строку, одинаковые ответы объединены вместе с источниками. Описание из карточки не повторяется рядом с заполненным company-level ответом о бизнесе. Различия стран, ролей, метрик и даты источников сохраняются. Полные observations, reasoning, excerpts, reviews и история остаются в базе. Кнопки refresh/research JSON/добавления компании и дополнительный английский заголовок убраны из вкладки; локальные API/MCP сохранены. Между фильтрами, счётчиком и таблицей увеличен отступ.

## Сохранность и проверки

Создана локальная WAL-aware копия с integrity_check до записи; она не отправлялась во внешний архив. Все прежние 127 вакансий совпали по всем полям; старые компании совпали кроме дополненных sourceLinks/updatedAt. Профили поиска и источники неизменны. Все прежние research observations/reviews/preferences сохранены. Счётчик provider_requests не вырос: quota-limited Adzuna/SerpAPI/Jooble и прочие подключённые API не вызывались; использованы публичные веб-материалы. Автоматическое расписание не включалось.

Проверены unit tests, сборка, HTTP/MCP на временных базах, валидация обоих изменённых скиллов и интерфейс в браузере. История: four-companies-source-directory-2026-10-21. Локальные preview/import/review/backup/verification квитанции: .runtime/company-links-2026-10-21/ (игнорируется Git).
