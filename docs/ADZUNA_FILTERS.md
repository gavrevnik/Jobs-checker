# Фильтры Adzuna

Проверено 03.10.2026 по [официальной OpenAPI-спецификации](https://developer.adzuna.com/swagger/spec/test2.json), [интерактивной документации](https://developer.adzuna.com/activedocs) и [примерам поиска](https://developer.adzuna.com/docs/search). Расширенные параметры доступны через MCP `jobs_search`, CLI `npm run tools` и HTTP `POST /api/source-tools/search`. В UI остаётся базовая форма поиска.

## Параметры

Все поля таблицы передаются внутри `adzuna`. `country` остаётся верхнеуровневым полем. Имена совпадают с API, флаги удобнее передавать JSON-значениями `true`/`false`: `true` отправляется как `1`, `false` не отправляет параметр и **не означает** противоположный тип занятости.

| Фильтр                     | Как применяется                                                           | Пример                                                                  |
| -------------------------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `what`                     | Поисковые слова                                                           | `product analyst`                                                       |
| `what_and`                 | Нужны все слова                                                           | `SQL Python`                                                            |
| `what_or`                  | Достаточно любого слова, не набора точных фраз                            | `analytics analyst`                                                     |
| `what_phrase`              | Точная фраза в заголовке или описании                                     | `product analyst`                                                       |
| `what_exclude`             | Исключить слова                                                           | `intern junior`                                                         |
| `title_only`               | Искать слова только в заголовке                                           | `analyst`                                                               |
| `where`                    | Центр поиска; переопределяет верхнеуровневый `location`                   | `Barcelona` или почтовый индекс                                         |
| `distance`                 | Радиус в км от `where`/`location`; у API по умолчанию 5 км                | `30`                                                                    |
| `location0` … `location7`  | Последовательные уровни географии из ответов API, без угадывания названий | `location0: "UK", location1: "South East England", location2: "Surrey"` |
| `salary_min`, `salary_max` | Нижняя и верхняя границы зарплатного поиска провайдера                    | `60000`, `100000`                                                       |
| `salary_include_unknown`   | Включать вакансии с неизвестной зарплатой                                 | `true`                                                                  |
| `max_days_old`             | Максимальный возраст объявления в днях                                    | `7`, `14`, `30`                                                         |
| `full_time`, `part_time`   | Полная или частичная занятость                                            | `full_time: true`                                                       |
| `permanent`, `contract`    | Постоянная работа или контракт                                            | `permanent: true`                                                       |
| `company`                  | Каноническое имя работодателя из ответа API                               | `Scopely`                                                               |
| `category`                 | Тег категории из `/jobs/{country}/categories` выбранного рынка            | `it-jobs` — если есть в рынке                                           |
| `sort_by`                  | Порядок выдачи                                                            | `date`, `salary`, `relevance`, `default`, `hybrid`                      |
| `sort_dir`                 | Направление сортировки                                                    | `up`, `down`                                                            |
| `page`                     | Начальная страница                                                        | `1`, `2`                                                                |
| `results_per_page`         | Размер страницы, в нашем адаптере 1–50                                    | `50`                                                                    |

`hybrid` в `sort_by` — алгоритм ранжирования, а не гибридная работа. Отдельных нативных фильтров remote, seniority, языка и visa sponsorship в этой спецификации нет. Наши `workMode`/`seniority` фильтруют нормализованный ответ локально; неизвестное значение не подтверждает соответствие.

Поддержанные в спецификации европейские рынки `country`: `es`, `de`, `fr`, `it`, `nl`, `be`, `at`, `ch`, `pl`, `gb`. Единого рынка «вся Европа» нет: страны опрашиваются отдельно. Полный список API также включает `us`, `au`, `br`, `ca`, `in`, `mx`, `nz`, `sg`, `za`.

## Семантика и ограничения

- Без блока `adzuna` сохраняется прежний поиск: keywords/синонимы превращаются в отдельные запросы, по 50 результатов, сортировка по дате. Начальная страница — 1.
- Любое явное поле `what`, `what_and`, `what_or`, `what_phrase` или `title_only` заменяет генерацию запросов Adzuna из `keywords`: выполняется один набор параметров. Комбинации этих полей передаются провайдеру совместно. Для других провайдеров блок не применяется.
- Локальные фильтры и профиль действуют дополнительно. `adzuna.salary_min` не равен `minSalary`: первый передаётся провайдеру, второй строго отбирает известную нижнюю границу с совпадающей валютой/периодом. Adzuna-оценки не превращаются в подтверждённую зарплату карточки. Чтобы сохранить объявления с неизвестной зарплатой, используйте `salary_include_unknown: true` и `minSalary: null`.
- У нативных зарплатных параметров нет выбора валюты/периода. Не выполняем конвертацию; суммы интерпретирует выбранный рынок Adzuna. Спецификация не уточняет период этих параметров: сверяйте вилку и её основание по оригиналу работодателя. Оценка агрегатора не гарантирует зарплату оффера.
- Верхнеуровневый `maxAgeDays` теперь также передаётся как `max_days_old`. Если заданы оба, провайдер получает меньшую границу, а локальная проверка продолжает действовать. Свежая дата в агрегаторе не доказывает, что работодатель ещё принимает отклики.
- `maxPages` ограничивает число страниц, начиная с `adzuna.page`. Каждая незакэшированная страница расходует один запрос независимо от числа вакансий. `maxRequests` остаётся жёстким бюджетом. Неполная выборка при исчерпании бюджета не импортируется.
- В dry-run `targets[].params` показывает эффективные параметры без секретов. Изменение фильтров создаёт отдельный ключ кэша. Локальный повторный анализ квоту не расходует.
- Отрицательные суммы/радиус, перевёрнутый диапазон, одновременно full-time/part-time или permanent/contract, неизвестные поля и радиус без центра отклоняются. Наши технические границы: возраст 1–365 дней, начальная страница 1–1000, до 50 результатов/страницу; это ограничения адаптера, не утверждение о максимумах API.

## Пример MCP / HTTP

```json
{
  "providers": ["adzuna"],
  "country": "es",
  "keywords": [],
  "exclude": [],
  "locations": [],
  "minSalary": null,
  "seniority": "any",
  "workMode": "any",
  "adzuna": {
    "what_phrase": "product analyst",
    "where": "Barcelona",
    "distance": 30,
    "salary_min": 60000,
    "salary_include_unknown": true,
    "max_days_old": 14,
    "full_time": true,
    "permanent": true,
    "sort_by": "date",
    "sort_dir": "down"
  },
  "maxPages": 1,
  "maxRequests": 1,
  "execute": false,
  "store": false
}
```

Сначала проверяется план. `execute: true` запускает поиск; `store: true` дополнительно сохраняет результаты в ATS. Сброс локальных фильтров в примере намеренный; профиль можно подключить и оставить его фильтры, если нужен более строгий отбор.

## Когда сбрасывается квота

[Условия Adzuna](https://developer.adzuna.com/docs/terms_of_service) подтверждают 25 запросов/минуту, 250/день, 1000/неделю и 2500/месяц. В публичных условиях, search-документации и OpenAPI нет подтверждения, является ли месяц календарным/скользящим/привязанным к регистрации, и нет часового пояса или точного времени сброса. Поиск в интернете 03.10.2026 также не дал надёжного подтверждения конкретного правила. Утверждать «Adzuna сбрасывается 1-го в UTC» нельзя.

Jobs checker использует **локальную оценку**: календарный месяц UTC, а короткие окна — скользящие. Это видно в подсказке счётчика. История не удаляется. Точное правило конкретного аккаунта можно уточнить в кабинете либо поддержке Adzuna; такой запрос от имени пользователя не отправлялся.
