# Поиск по европейским рынкам

| Источник          | Покрытие этой задачи                                                                                   | Доступ                                                                        |
| ----------------- | ------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| Adzuna            | ES, DE, IT, FR, GB. PT, CY, SE, NO, DK и FI отсутствуют в опубликованном списке                        | Существующий ключ. Проверяйте тариф в аккаунте, локальные пределы сохраняются |
| Arbeitnow         | DE, GB, FR                                                                                             | Без ключа, кэш 1 ч                                                            |
| JobTech JobSearch | SE, вакансии Platsbanken                                                                               | Без ключа, CC0                                                                |
| Himalayas         | Удалённые роли с допуском из выбранных стран. Поиск по стране не означает покрытие её локального рынка | Без ключа, общий анонимный лимит                                              |

В интерфейсе есть пресеты «Европа» и «Nordic с Финляндией», выбор по умолчанию не меняется. GB — весь рынок Великобритании. Для поиска именно по Англии проверяйте регион по объявлению. PT, CY, NO, DK и FI в этой конфигурации доступны через удалённые роли Himalayas; матрица не обещает покрытие местных досок. Запрос к общим лентам Remotive и Jobicy выполняется один раз, с отбором по географии вакансии в ходе проверки. Jooble остаётся на прежней конфигурации.

На один запуск действуют `maxRequests`, `maxPages` на цель и `maxItems` на выдачу. Dry-run показывает пары источник–рынок, пропуски и верхнюю границу сетевых запросов. У JobTech и Himalayas локальный предел 10 запросов в минуту на провайдер; при HTTP 429 учитывается `Retry-After`. Это ограничения приложения. Сравнение компаний не запускает поиск.

Himalayas сохраняет отдельные URL объявления и отклика, страны допуска, часовые пояса, дату обновления источника и срок отклика. `jobs_enrich` проверяет конкретное объявление по публичному API (200 — открыто у Himalayas, 410 — закрыто, 404 — неизвестно). 410 сохраняется как закрытие у источника, если нет свежего официального подтверждения открытости. 200 сам по себе не является проверкой официального Careers работодателя. JobTech хранит дату публикации и срок отклика отдельно. Истёкший срок или явное удаление исключают находку из нового отбора; отсутствие в поисковой выдаче не закрывает ранее сохранённую роль.

Проверено 11.11.2026: по одному публичному GET и по одному поисковому запросу через Jobs Checker с временной SQLite в памяти для Himalayas FR, JobTech SE и Arbeitnow FR. Все три вернули JSON; живые результаты в рабочую базу не импортировались.
