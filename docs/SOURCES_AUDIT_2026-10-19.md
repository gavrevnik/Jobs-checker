## Пять контрольных вопросов

1. **SerpAPI organic:** отсутствует; общий коннектор задаёт только google_jobs.
2. **LinkedIn identity:** URL/slug, необязательный числовой ID и evidence сохраняются; автоматическое извлечение f_C и отдельные discovery/confirm operations отсутствуют.
3. **Повторный refresh:** агентский сценарий в скилле есть, автоматизированного LinkedIn workflow в приложении нет.
4. **Web search execution:** `jobs_web_search_plan` только генерирует запросы/URL. Агент в чате действительно может выполнять собственный web search; это внешняя возможность агента, не встроенный search executor сервера.
5. **Общая ATS/dedupe:** проверенные ссылки можно импортировать в одну jobs DB, совпадающий canonical ATS URL сохраняет одну карточку. Специальной нормализации LinkedIn numeric Job ID, региональных доменов, slug URL и trk-параметров нет; cross-source LinkedIn↔ATS equivalence не устанавливается автоматически. Поэтому универсальную дедупликацию уже готовой считать нельзя.

Точки кода: `shared/model.ts::canonicalUrl`, `server/store.ts::findDuplicate`, `shared/company-hiring.ts`, `server/source-tools.ts::webPlan/monitor`, `shared/source-tools.ts::webSearchPlan`, `personal-radar/connectors/connectors-ts/src/job/serpapi/index.ts`. Гарантия скилла о проверке/дедупликации не заменяет отсутствующую реализацию LinkedIn identity parser.

Gmail отдельно: [актуальные quotas](https://developers.google.com/workspace/gmail/api/reference/quota) изменены с 01.05.2026 для новых проектов: 6000 quota units/мин на user/project и 1 200 000/мин на project; порог daily billing — 80 млн units, это не количество писем/запросов. У старых проектов могут сохраняться прежние квоты. [Quickstart](https://developers.google.com/workspace/gmail/api/quickstart/python), [LinkedIn alerts](https://www.linkedin.com/help/linkedin/answer/a511279/job-alerts-on-linkedin?lang=en-us). Реальный Cloud project здесь не создавался, billing не подключался.

## Рекомендуемый порядок

1. Официальные ATS: подключить проверенные недостающие доски и адресно закрывать Careers/Workday-пробелы.
2. Общие job API: бесплатный Jobicy реализован и проверен на mocks; следующий шаг — измерить отдачу разрешённого поиска. Reed — при отдельном UK-приоритете. Сохранить Remotive/Arbeitnow/Adzuna в текущих лимитах; не включать Jooble как частый мониторинг.
3. Google Jobs: существующий SerpAPI использовать точечно по отдельному запросу; новый платный тариф пока не нужен по имеющейся локальной загрузке.
4. LinkedIn через organic web search: сначала LinkedIn Job ID/canonicalization и проверка cross-source equivalence, затем engine=google + company-aware plan/refresh на общей квоте.
5. Alerts/email: после измерения покрытия первых четырёх каналов; начать с нескольких приоритетных alerts и ручного импорта примеров писем.

Это предложение следующей работы, не её запуск. Общие аккаунты SerpAPI/Adzuna/Jooble могут использоваться другими runtime; локальный журнал Jobs Checker не подтверждает баланс общего аккаунта. Соседних прямых клиентов этих providers в целевой инспекции не найдено; shared library сама по себе не расходует квоту.

## Проверка изменения интерфейса

В модалке две группы: пять источников с малым лимитом/редким обновлением (Adzuna, SerpAPI, Jooble, Remotive, Jobicy) и пять публичных API без подключённой малой тарифной квоты (Arbeitnow, Greenhouse, Lever, Ashby, SmartRecruiters). Во второй группе отдельно описаны Careers, LinkedIn и прочие веб-площадки, способ запуска и учёт. Все прежние статусы, лимиты, расход за сегодня/цикл и ссылки на условия сохранены. Неизвестный предел не объявляется гарантированными 1000+ запросов/день.

При первоначальном аудите: 141 tests / 18 files и production build успешны. В браузере проверены состав обеих групп и веб-блок; console warn/error отсутствуют. Provider attempts в SQLite остались 249, из них SerpAPI 10: внешние provider API этой проверкой не расходовались. Источники условий и скриншоты сохранены в ignored `.runtime/sources-audit-2026-10-19/`.

## Дополнение: ручные сценарии и Jobicy

Скиллы разделены на jobs-discovery, jobs-monitoring, jobs-pool-review; общий evidence/import/quota контракт — discovery/workflow-common.md. Workday и Indeed/WTTJ/Wellfound/EURES явно включены в адресный веб-поиск. Jobicy добавлен на бесплатной основе без ключа/кошелька/платных URLs; default search теперь Arbeitnow/Remotive/Jobicy. Проверка дополнения: 156 tests / 21 files Jobs Checker, 71 offline tests общего пакета, обе production сборки, HTTP и MCP smoke — успешно. Все три SKILL.md прошли quick_validate; локальные ссылки проверены. Модалка проверена в браузере на отдельной синтетической базе: 5 + 5 API-источников, Jobicy, Workday и остальные web-каналы. Текущий Jobs Checker штатно перезапущен; /api/source-tools возвращает 10 адаптеров, Jobicy ready. Внешних provider API вызовов и живого импорта этим изменением не было.
