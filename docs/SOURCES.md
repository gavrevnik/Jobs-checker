# Источники и стратегия поиска

Историческое исследование от 21 сентября 2026 года. Актуальная реализация и расширение от 2–3 октября: [JOB_SOURCES_RESEARCH.md](JOB_SOURCES_RESEARCH.md). Описанные ниже пять коннекторов сохранены; новая вкладка добавляет SmartRecruiters, Arbeitnow, SerpAPI и Jooble.

Для одного пользователя разумно сочетать широкое обнаружение вакансий и адресное наблюдение за выбранными компаниями. Обязательная платная подписка или LLM для первичного сбора не нужны. Локальная база остаётся общей точкой приёма: результаты из внешнего исследования имеют ту же структуру, что ручной ввод и API.

## Реализованные коннекторы

| Источник   | Роль                                      | API / доступ                                                                                   | Ограничения                                                                                           |
| ---------- | ----------------------------------------- | ---------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Remotive   | Открытие новых компаний и удалённых ролей | `GET https://remotive.com/api/remote-jobs`, без ключа                                          | API-выборка не равна всему рынку; задержка 24 часа, максимум 4 успешных обновления/сутки в приложении |
| Greenhouse | Наблюдение за конкретным работодателем    | `GET https://boards-api.greenhouse.io/v1/boards/{token}/jobs?content=true`, публичный GET      | Нужно знать board token; prospect-записи не загружаются                                               |
| Lever      | Наблюдение за компанией                   | `GET https://api.lever.co/v0/postings/{site}?mode=json&limit=100&skip=...`, без ключа          | Пагинация; отдельный EU endpoint; это не глобальный полнотекстовый поиск                              |
| Ashby      | Наблюдение за компанией                   | `GET https://api.ashbyhq.com/posting-api/job-board/{name}?includeCompensation=true`, без ключа | Не перечисленные на доске публикации (`isListed=false`) не импортируются                              |
| Adzuna     | Широкий поиск по роли и рынку             | `GET https://api.adzuna.com/v1/api/jobs/{country}/search/{page}`, APP ID + ключ                | До 3 страниц по 50 в этой версии; ключи, доступ и квоты — у пользователя                              |

### Первичные источники

- [Remotive: официальный публичный API и условия](https://github.com/remotive-com/remote-jobs-api). Сохраняются название источника и оригинальный URL Remotive. Автоматического экспорта на сторонние доски объявлений нет.
- [Greenhouse: Job Board API](https://docs.greenhouse.io/job-board.html). Чтение опубликованных вакансий не требует авторизации. Harvest API и отправка откликов не используются.
- [Lever: официальная документация Postings API](https://github.com/lever/postings-api). Используются публичные global/EU списки, обработана пагинация.
- [Ashby: Job Postings API](https://developers.ashbyhq.com/docs/public-job-posting-api). Это публичный posting-api, не защищённый `jobPosting.list` API.
- [Adzuna: Search API](https://developer.adzuna.com/docs/search), [регистрация разработчика](https://developer.adzuna.com/).

## Почему такая схема

ATS дают структурированные объявления непосредственно с карьерных страниц. Для небольшого списка компаний это проще поддерживать и точнее, чем отдельные HTML-парсеры. Но ATS требуют известных идентификаторов, поэтому сами по себе не решают поиск новых компаний. Remotive и необязательная Adzuna покрывают это направление, а ручной импорт расширяет базу на любую отрасль и источник.

LinkedIn, Indeed, Google Jobs и произвольные карьерные сайты в этой версии доступны через ссылки и ручные подборки. Обход авторизации и нестабильные HTML-парсеры не включены. Если выбранный пользователем рынок плохо покрывается текущими источниками, стоит добавить специализированный коннектор по документированному API, а не подключать ещё один сервис без доказанной пользы.

## Результат живой проверки

21.09.2026 публичные endpoints успешно ответили: Remotive — 18 публикаций в текущем ответе, Greenhouse (`greenhouse`) — 21, Ashby (`Ashby`) — 72. Lever (`lever`) вернул корректный пустой массив. Количество не является обещанием размера базы: оно меняется у провайдера. Пагинация Lever дополнительно проверена на фикстуре из 101 записи.

Adzuna без личных ключей проверена только на контракте адаптера и образцах данных, а не живым запросом. Поиск и отслеживание уже работают без неё.
