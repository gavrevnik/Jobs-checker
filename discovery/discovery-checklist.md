# Discovery checklist

Актуальный реестр `criteria.json` — источник ID, типов и правил. Unknown ≠ fail. Проверять конкретное содержание первичного источника, scope и даты. Отзывы и рыночные оценки — отдельные сигналы, не установленные условия компании.

Для колонки «Аналитика» продолжай собирать факты прежних Highlights: AN01/AN04/AN06/T03 и содержательные AN07/AN08. Источники, границы выводов, форматы значений и связь с тегами описаны в [правилах тегов](analytics-tags.md), раздел «Аналитика: источники и факты прежних Highlights». AN09_CULTURE не заменяет эти структурированные observations; скрытие колонок не отменяет критерии.

## A01 · Языки (Доступность)

Какие языки указаны для продуктовой команды?

Тип: `strings`; scored. Правило: en/english/английский или ru/russian/русский → pass; иной явно полный перечень → fail.

Допустимые источники: job, official, report. Careers/вакансии для условий; Engineering/Data Blog, доклады и репозитории для технологий; отчётность/IR для бизнеса; отзывы для культуры; B03 — пользователь. Конкретное проверенное содержание допустимого источника отвечает на исследуемый вопрос и соответствует scope. Для boolean false требуется явное отрицание, а не отсутствие упоминания. Только указанный scope: страна, город, роль, job_url. Условия вакансии не являются политикой компании.

Unknown: Нет конкретного содержания источника, источник не проверен/устарел или не соответствует scope. Отсутствие публичных сведений не означает fail. Для неполного перечня отсутствие подходящего значения остаётся unknown (complete=true требует явно полного перечня). Интервью: `A01-I`.
